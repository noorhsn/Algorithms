# Study Notes

This directory contains study notes on various algorithms and data structures.

## Organization

Notes are organized by topic. Each topic may have its own subdirectory or markdown file.

## Topics to Cover

- Sorting Algorithms
- Searching Algorithms
- Graph Algorithms
- Dynamic Programming
- Greedy Algorithms
- Divide and Conquer
- Data Structures (Arrays, Linked Lists, Trees, Graphs, etc.)
- Complexity Analysis

## Format

Each note should include:
- Algorithm description
- Time and space complexity
- Implementation examples
- Use cases
